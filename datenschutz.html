Datenschutz.

Transparenz darüber, welche Daten PennyPinguin verarbeitet und was beim Besuch dieser Website passiert.

Die App

Deine Finanzdaten bleiben auf deinem Gerät.

PennyPinguin ist als lokal arbeitende Finanz-App konzipiert.

Die von dir innerhalb der App eingegebenen Finanzdaten werden lokal auf deinem iPhone verarbeitet und gespeichert.

PennyPinguin benötigt für die Verwaltung deiner Finanzdaten keinen PennyPinguin-Benutzeraccount und keine Verbindung zu deinem Bankkonto.

Die App überträgt deine in PennyPinguin gespeicherten Einnahmen, Ausgaben, Finanzierungen oder Kategorien nicht an einen PennyPinguin-Server.

CSV-Import

Import direkt auf deinem iPhone.

Wenn du eine CSV-Datei in PennyPinguin importierst, wird die Datei auf deinem Gerät eingelesen und verarbeitet.

Die darin enthaltenen Buchungsdaten werden nicht zur Verarbeitung an einen PennyPinguin-Server übertragen.

Nach dem Import werden die daraus übernommenen Buchungsinformationen als lokale PennyPinguin-Daten gespeichert.

Benachrichtigungen

Erinnerungen bleiben unter deiner Kontrolle.

PennyPinguin kann lokale Benachrichtigungen für Zahlungserinnerungen und Finanz-Checks verwenden.

Hierfür verwendet die App das Benachrichtigungssystem von iOS.

Du kannst die Berechtigung für Benachrichtigungen jederzeit über die iOS-Einstellungen verwalten oder entziehen.

Speicherung

Du entscheidest, was auf deinem Gerät bleibt.

Von dir erstellte und importierte Finanzdaten verbleiben grundsätzlich auf deinem Gerät, bis du sie selbst löschst beziehungsweise die lokale App-Speicherung entfernt wird.

PennyPinguin führt derzeit kein eigenes serverseitiges Benutzerkonto für deine persönlichen Finanzdaten.

Bitte beachte, dass beim Löschen der App auch lokal gespeicherte App-Daten verloren gehen können.

Diese Website

Hosting über GitHub Pages.

Diese Website wird derzeit über GitHub Pages bereitgestellt.

Beim Aufruf der Website können technisch erforderliche Daten durch den Hostinganbieter verarbeitet werden.

Dazu können insbesondere technische Verbindungsinformationen gehören, die für die Bereitstellung und Sicherheit der Website erforderlich sind.

PennyPinguin setzt auf dieser Website derzeit keine eigenen Analyse-, Werbe- oder Marketing-Trackingdienste ein.
